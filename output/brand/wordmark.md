# Official ICSphere wordmark

The approved all-white wordmark is saved at `public/brand/icsphere-wordmark.png` and used in the landing header, hero, and footer. It is the approved v3 artwork, renamed without changing its pixels. Earlier project concepts have been removed.

The source is a 2048 by 683 PNG with a dark background. Landing CSS crops its presentation margins and uses lighten blending on dark surfaces. It is not a transparent or vector asset and should not be used on light surfaces without a separate export. Keep accessible text on the consuming heading or home link.

On mobile, the landing header displays only the ICS initials cropped from the same approved artwork. The hero and footer retain the full wordmark, as does the desktop header.

Created and refined with the built-in image generation tool. A subsequent transparent conversion was rejected because it altered the edges; the approved artwork is retained.
